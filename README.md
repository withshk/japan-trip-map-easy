# 간사이 단풍 여행 지도 (여유 버전)

2026.11.22 - 11.26 오사카·교토 여행 일정을 날짜별 경로로 보여주는 지도.

## 배포

빌드할 거 없이 이 폴더 그대로 올리면 됨.

- **GitHub Pages**: 저장소에 올리고 Settings > Pages에서 main 브랜치 루트 선택
- **Vercel / Netlify**: 폴더를 그대로 import (Framework: Other, 빌드 명령 없음)

## 로컬에서 보기

```
python3 -m http.server
```
그다음 http://localhost:8000
